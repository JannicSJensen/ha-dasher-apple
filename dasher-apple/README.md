# Dasher Apple

An independent, Apple-inspired Home Assistant dashboard for older iPads.

Open the sidebar entry or `http://<home-assistant>:8100/` for ten configurable faces, horizontal swipes, a visual face chooser, night mode, home controls, clocks, weather, photos and camera snapshots.

Edit `dashboard.yaml` in this app's configuration folder to choose entities and actions. Photos and cameras are disabled by default. The direct port does not require a login; restrict access to your trusted network.

This web interface targets iOS 12.5.8, but physical-device verification is still needed. It is not a native Apple app or an Apple-affiliated product.

See the **Documentation** tab for setup, compatibility and privacy details.
